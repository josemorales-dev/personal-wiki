# Obsidian vault

Vault: `~/Jose's Vault` (quote the path; it contains a space and an apostrophe).

- Read a note before changing it, and edit in place so existing content,
  frontmatter, and block IDs survive.
- Link notes with wikilinks: `[[Note name]]`, `[[Note name#Heading]]`,
  `![[attachment.png]]` for embeds.
- Name a note by its title (`Weekly Review.md`); the filename is the link
  target, so renaming one means updating every `[[link]]` to it.
- Put metadata in YAML frontmatter (`tags`, `aliases`, dates as `YYYY-MM-DD`).
- Leave `.obsidian/` to Obsidian; it holds app settings and plugin state.
