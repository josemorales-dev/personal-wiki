# Agent workflow

Read [references/WORKFLOW.md](references/WORKFLOW.md) for repository changes, cleanup, or Git actions.

Starting a session: read the plan, scratch, and controls formats below, write `.agents/sessions/<id>/PLAN.md` and `SCRATCH.md`, and add both to `.agents/CONTROLS.md`. Apply `SCRATCH.md` after the user approves it. Read the issue references for local issue work.

- [references/PLAN-FORMAT.md](references/PLAN-FORMAT.md): session plans.
- [references/SCRATCH-FORMAT.md](references/SCRATCH-FORMAT.md): the session's exact changes, for approval.
- [references/CONTROLS-FORMAT.md](references/CONTROLS-FORMAT.md): active session tracking.
- [references/issue-tracker.md](references/issue-tracker.md): issue destinations and permissions.
- [references/triage-labels.md](references/triage-labels.md): fallback local triage states.

Apply code and language standards relevant to the actual project.
