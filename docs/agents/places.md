# Places

Where named projects and folders live on this machine. Use it to turn a name the user says ("the member app", "the calendar") into a path.

The table holds only what the disk cannot tell you: the name people use, and what the thing is for. Get remotes, branches, and worktrees from `git`, and active work from `sessions list`.

When you work in a place that is missing, add a row. When a path no longer exists, fix or remove its row.
